# Strata на 3 × CMP50HX: настройка и измерения

Публикация информации об уже работающей установке, обследованной 6 октября 2026 года, и завершённой tuning-кампании 7 октября. Это не новый форк Strata, не новый бинарник и не проверенный установщик. Первоначальный аудит и последующие тесты приведены отдельно; исходная сборка и конфигурация по итогам tuning не менялись.

## Измеренная конфигурация

- Qwen3.8-Flash-Next-GSQ-RCO Q2_0, два GGUF-шарда.
- Три CMP50HX по 20 ГиБ: GPU 0, 1, 2; 48 слоёв, границы `16,32`. Четвёртая карта не участвует.
- Контекст 262144, KV `int8`, prefill 2048, два batch-слота (`parallel=2`).
- MTP включён: `--spec 4`, `--spec-min-p 0.5`; experts cache `auto`, `--pcie-frac 0`.
- Ubuntu 24.04.4, Python 3.12.3, CUDA toolkit 12.8, драйвер 610.43.03.
- Xeon E5-2620 v0, AVX без AVX2/FMA/F16C, около 15 ГиБ RAM; mmap экспертов существенен для этой установки.

## Результаты

Медианы. Thinking выключен; prefix cache в одиночном основном ряду не использовался. PP и decode — серверные фазы; первый токен — клиентский TTFT.

| Входные токены | Повторы | Выходные токены | Prefill, ток/с | Decode, ток/с | TTFT, с |
|---|---:|---:|---:|---:|---:|
| 241–247 | 3 | 512 | 262,0 | 72,9 | 0,97 |
| 4119–4121 | 3 | 512 | 1156,6 | 71,5 | 3,68 |
| 32116–32121 | 3 | 512 | 1949,6 | 68,9 | 17,21 |
| 120120–120121 | 2 | 512 | 2107,0 | 69,0 | 59,64 |
| 250121 | 1 | 512 | 1928,5 | 59,7 | 135,06 |
| 24862–24863, исходный код | 3 | 401–512 | 1774,3 | 76,9 | 14,38 |

250K-запрос завершился за 143,62 с. Это один прогон, а не статистически устойчивый результат на полном лимите 262144.

Два клиента, каждому ~4K входа +512 выхода, три пары: **45,24 выходных ток/с суммарно**, медиана с учётом prefill/admission. TTFT первого клиента 3,68–3,91 с, второго 10,52–10,84 с. Это не чистый concurrent decode. `parallel=2` работает, но не удвоил throughput в этой серии. При переходах solo → batch → solo поле `predicted_per_second` может относиться только к последнему сегменту ответа.

Повтор одинакового 4K-префикса сократил серверный prefill с 3518,7 до 88,1 мс; такой повтор нельзя выдавать за некешированный PP-тест.

## Проверить опубликованные результаты без GPU

Требуется Python 3, внешних пакетов не нужно:

```bash
python3 tools/aggregate.py
```

Скрипт проверяет количество запросов, выходные токены, завершение SSE, отсутствие reasoning и prefix reuse в solo-таблице, затем пересчитывает `results/2026-10-06/summary.json`. Он не обращается к серверу. При публикации пересчитанная сводка полностью совпала с исходной.

## Безопасность и границы

Наблюдавшийся профиль слушал `0.0.0.0:8080` без ключа с `api_monitor=true`. **Не переносите его в открытую сеть.** Доступ из Интернета не проверялся. Loopback-пример не содержит полноценного auth/TLS; внешний доступ требует отдельного защищённого proxy/VPN/ACL.

Основной длинный вход — синтетическая последовательность слов; дополнительно использован исходный код. Не проверялись качество long-context retrieval, MTP-off A/B, vision, полный 262K на каждом из двух клиентов, новая сборка, чистая установка, reboot-chain и ночная устойчивость. Скрипты benchmark создают реальную нагрузку только при явном запуске пользователем.
